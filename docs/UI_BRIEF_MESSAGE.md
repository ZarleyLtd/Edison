# Brief message

Edison uses the shared CursorSites brief-message pattern for short feedback on the control you just used (token saved, moment filed, note added).

- Canonical spec: [cursor-sites-shared/ui/BRIEF_MESSAGE.md](../../cursor-sites-shared/ui/BRIEF_MESSAGE.md)
- Files in this repo: `assets/js/utils/brief-message.js` and `assets/css/brief-message.css`
- Sync from the shared folder with `cursor-sites-shared/scripts/sync-ui.ps1`. Edison is one of the projects that script updates.

Errors that need a decision stay in the red banner. Brief messages are only for confirmation.
