# Edison tickets

Issues labeled `edison` were filed in Edison. When a comment mentions `@claude`:

- Read the issue body, comments, and linked screenshots.
- If a pull request for this issue is already open, continue from the commits on that branch. Do not open another pull request. Act on every note left since the last round, oldest first.
- Otherwise implement the change on a new branch and open a pull request that references the issue number. Do not merge.
- Comment a short summary of what changed and how to review it.
- When the round is on the pull request, replace `stage:working` with `stage:review`, including when no code change was needed.
- If you are blocked, comment the question and replace the `stage:working` label with `stage:needs-input`.
